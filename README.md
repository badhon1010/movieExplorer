# 🎬 MovieExplorer

A sleek, responsive, and highly interactive Single Page Application (SPA) for discovering movies and TV shows, built with React and powered by the TVMaze API.

## ✨ Features

- **Cinematic Dark Theme:** A premium, modern UI featuring glassmorphism elements, dynamic hover animations, and a responsive grid layout.
- **TVMaze API Integration:** Fetches and displays real-time data for movies and TV shows directly from a live database.
- **Smart Search with Auto-Suggest:** Instantly find your favorite shows using the search bar with a live, debounced auto-suggestion dropdown.
- **Detailed Movie Insights:** Click on any movie card to open a beautifully styled modal displaying the poster, summary, rating, release year, runtime, and genres.
- **Responsive Design:** Fully optimized for seamless viewing across mobile, tablet, and desktop screens.
- **Dynamic Routing:** Built with `react-router-dom` for smooth, instant navigation between the Landing page and Movie Explorer pages.
- **Modern Typography:** Combines *Montserrat* for bold, cinematic headings and *Poppins* for highly legible body text to give the app a premium streaming-service feel.

## 🛠️ Technology Stack

- **Frontend Framework:** React 18 (Vite)
- **Styling:** Tailwind CSS v4 & Vanilla CSS Variables
- **Routing:** React Router v6
- **Icons:** Lucide React
- **API:** [TVMaze REST API](https://www.tvmaze.com/api)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
Make sure you have Node.js installed on your computer.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/movieExplorer.git
   cd movieExplorer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
